BSAHI Research

Bitcoin Resource Accounting — the research program of Bitcoin Sahi: a complete accounting system for every long-lived resource Bitcoin consumes (replicated storage, UTXO state, validation, relay, bandwidth), quantifying how much of each cost the fee market internalizes. SCCR (storage) is Metric #1 — the first measured member of the RIR family; the rest are research hypotheses. Open research on block space economics — the fee market, mempool dynamics, and the permanent cost of data storage.

SCCR is an upper bound. N = 26,586 is the observed reachable population; non-listening/private nodes are unobservable, and counting them (they bear cost too) would lower the ratio. Population scenarios — 50K, 100K, and ~265.9K under a historical 9:1 assumption (not a measured count) — are shown in the sensitivity note.

Definitions

Self-contained definitions for the terms used across this library.

SCCR — Storage Cost Coverage Ratio
Transaction fees paid (USD) divided by the modeled 10-year storage cost borne by full nodes (USD) at a node count N. A ratio below 1.0 means fees do not cover the modeled cost of storing the data across the network. Because only listening nodes are observable, the reported ratio is an upper bound: counting non-listening/private nodes would enlarge the denominator and lower it.
N — node count
The number of full nodes bearing the storage cost. Primary source: a measured reachable-node count (validating; a floor) (btcnodes crawl, 2026-09-16); the canonical constant is 26,586, a lower bound. An earlier addrman address sample (≥32,000 gossiped addresses) was never a node count.
T — storage time horizon
The assumed lifetime over which stored data is borne by nodes. T = 10 years.
L_net — modeled network storage cost
The modeled per-block storage cost across the network, in USD. At N=26,586 and T=10 yr it is $4,675.65 per block (model-spec v2.1.1).
