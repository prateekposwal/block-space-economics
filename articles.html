Can You Count the Nodes That Cannot Be Counted?

Non-listening nodes — behind NAT, never accepting inbound — are invisible to every crawler. The only way to observe them is to be reachable yourself and count who dials in. This machine sits behind carrier-grade NAT (five stacked private hops, a shared public IP), and the carrier firewalls inbound IPv6. So we borrowed a public IPv6 and ran a PROXY-protocol relay that preserves the peer's real source address. The tunnel came up and the SYNs arrived — but macOS sent the replies out the wrong interface. A packet capture found it; one routing fix later, an external host reached our node with its address intact.
